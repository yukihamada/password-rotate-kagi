# パスワード変更＋Kagi移行エージェント — 配布パッケージ

タイムズカー等の大規模情報漏えいの後に、**誰でも安全に**パスワードを変更し、Kagi検索へ移行するためのチェックリストと手順書です。

## これは何？

- 2026年9月のタイムズカー不正アクセス（最大約660万件、免許証画像約160万件）を受けて作成
- パスワード変更・MFA設定・Kagi移行の**手順書**
- Kagiクレジットを配布したい人向けの**設計ガイド**

## 対象

- タイムズカー会員・退会済み・入会未完了・法人会員
- パスワードを使い回している人
- Kagiに移行したい人
- 被害者にKagiクレジットを配りたい人

## 使い方

### 個人で使う

1. `SKILL.md` を開く
2. 上から順にチェックリストを実行
3. 完了したら✓をつける

### 配布する（クレジットを配りたい人）

**推奨：Kagi公式ギフト機能を使う（身内・知人限定）**

不特定多数への配布は費用と被害者確認のコストが見合わないため、**被害者であることが確実な身内・知人に限定**するのが現実的。

1. 配布者本人がKagiで有料プランを契約（ギフト購入の前提条件）
2. `SKILL.md` の「6. クレジット配布の設計」を読む
3. 配布フローに沿って、Kagi Settings → Gifts からギフトリンクを発行して配布

不特定多数に配布する場合は `distribution/` フォルダのテンプレートを使うが、費用と確認コストを十分に検討すること。

## 重要な注意

- **パスワード・APIキー・カード番号は絶対に他人に見せない・貼らない**
- 実際のログイン・課金・クレジット発行は**すべて本人が行う**
- このパッケージは手順の提示のみ。実行は本人の責任で行う
