# パスワード変更＋Kagi移行 — 最小手順パッケージ

タイムズカー等の大規模情報漏えいの後に、**最小の手間で最大の効果**を出すためのチェックリストと手順書です。

## これは何？

- 2026年9月のタイムズカー不正アクセス（最大約660万件、免許証画像約160万件）を受けて作成
- **S級（メール・金融）だけ変えれば被害は大幅に減る**という最小手順
- MFA設定とKagi移行でセキュリティを強化

## 対象

- タイムズカー会員・退会済み・入会未完了・法人会員
- パスワードを使い回している人
- Kagiに移行したい人

## 使い方

### 個人で使う

1. `SKILL.md` を開く
2. 上から順にチェックリストを実行（合計20〜30分）
3. 完了したら✓をつける

### 配布する（クレジットを配りたい人）

**推奨：Kagi公式ギフト機能を使う（身内・知人限定）**

不特定多数への配布は費用と被害者確認のコストが見合わないため、**被害者であることが確実な身内・知人に限定**するのが現実的。

1. 配布者本人がKagiで有料プランを契約（ギフト購入の前提条件）
2. Kagi Settings → Gifts からギフトリンクを発行
3. リンクをLINE/メールで送信

詳細は `distribution/` フォルダのテンプレートを参照。

## セキュリティ強化のポイント

- **パスワードマネージャを使う**：1Password/Bitwarden/iCloudキーチェーン等
- **16文字以上のランダム**：辞書にある単語・誕生日・連番は絶対に使わない
- **使い回し禁止**：1サービス1パスワード
- **メール内リンクを開かない**：公式アプリまたはブックマークからアクセス
- **SMS認証を避ける**：SIMスワップ攻撃で突破される。認証アプリまたは物理キーを使う

## 重要な注意

- **パスワード・APIキー・カード番号は絶対に他人に見せない・貼らない**
- 実際のログイン・課金・クレジット発行は**すべて本人が行う**
- このパッケージは手順の提示のみ。実行は本人の責任で行う
