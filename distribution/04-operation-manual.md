# 配布運用マニュアル（配布者向け）

## 推奨スコープ：身内・知人限定

不特定多数への配布は、費用（1人$10×人数）と被害者確認のコストが見合わない。**タイムズ漏えいの被害者であることが確実な身内・知人に限定**するのが現実的。

## 身内・知人への配布（推奨）

1. **Kagi有料プラン契約**（ギフト購入の前提）
   - https://kagi.com/signup でアカウント作成
   - Professional（$10/月）または Ultimate（$25/月）を契約

2. **配布対象を決める**
   - タイムズカー会員・退会済みであることが確実な人
   - 予算：1人$10 × 人数

3. **ギフトリンク発行**
   - https://kagi.com/settings/gift で$10を選択
   - カードで支払い
   - 発行されたギフトリンクをコピー

4. **送信**
   - LINEやメールでギフトリンクを送る
   - `03-gift-email-template.md` の文面を参考に

5. **記録**
   - 配布済みリストをメモ（重複防止）

## 不特定多数への配布（非推奨・上級者向け）

費用と確認コストを十分に検討した上で実施すること。

### 事前準備（初回のみ・約15分）

1. **Kagi有料プラン契約**（上記と同じ）
2. **申請フォーム作成**
   - https://forms.new を開く
   - `01-google-form-template.md` の内容を貼り付けて作成
3. **記録用スプレッドシート作成**
   - https://sheets.new を開く
   - `02-ledger-template.csv` のヘッダー行を貼り付け
4. **上限を決める**
   - 1人あたり: $10（Professional 1ヶ月分）
   - 総額上限: ____ドル（例：$500 = 50人分）

### 配布フロー（1人あたり約3分）

1. **申請確認**: Googleフォームの回答を開く
2. **被害者確認**: 申請内容を確認（関係・確認事項のチェック）
3. **重複チェック**: スプレッドシートで同じメールアドレスがないか検索
4. **ギフト発行**: https://kagi.com/settings/gift で$10を選択→カードで支払い→ギフトリンクをコピー
5. **送信**: `03-gift-email-template.md` の文面でギフトリンクを送信
6. **記録**: スプレッドシートに記入（ステータス: 送信済み）
7. **残数確認**: 上限に達したらフォームを閉じる

### 配布終了後

1. フォームを閉じる
2. 収集したメールアドレスを削除（フォームの回答とスプレッドシートのメールアドレス列を消去）
3. 配布結果を記録（配布人数・総額）

## 注意

- Kagiのログイン情報・カード情報は絶対に他人に見せない
- ギフト購入は必ずKagi公式サイトで行う
- 申請者の個人情報は最小限にとどめ、配布後は速やかに削除する
